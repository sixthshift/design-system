# Palette

</div>

The raw colour scales — five families, eleven stops each. The palette is not a
layer: it is referenced only by the semantic tokens in `theme.css`, never by a
component, and it is not API for consumers either. It is the authoring
convention that keeps the theme's values coordinated — a re-skin edits the
semantic layer, and in practice you do it here, by re-mixing what the semantic
tokens point at. [Theming](?path=/docs/design-system-theming--docs) describes
the layers themselves.

Every swatch below is read out of the stylesheet at render time, hex and
measured lightness both. Nothing on this page is typed out by hand.

## The spine

The families are not five independent choices. Each runs on **one shared OKLCH
spine**: the same eleven lightness stops, one chroma envelope peaking at
500–600, and one hue held constant down the ramp.

<SpineChart />

Five lines lying on top of each other is the argument. Three properties follow
from it, and each one is a defect this system's first palette had before the
spine construction:

**A stop means the same thing in every hue.** A `red-300` badge and a
`green-300` badge carry equal visual weight. In the pre-spine palette the same
stop varied by up to .115 in lightness between families, which is what made the
system read as unconsidered.

**A state change is a deepening, not a hue shift.** Hue is constant per family,
give or take 8° of drift toward the ends that corrects for the Abney effect. The
old brand blue swung 252°→269° down its ramp with chroma zig-zagging, so a
button hover — 600 → 700 — changed colour family rather than getting darker.

**No cliffs.** Lightness is monotonic and evenly stepped — no stop where the
ramp falls .21 while every other step moves about .08, which is what two ramps
glued together look like.

### Why the neutral leaves the bundle

`sand` runs deeper than the chromatic spine from 700 down — the one divergence
visible in the chart. The neutral carries surfaces rather than accents:
`sand-900` is the dark-mode page background, so it has to reach a real dark
(L=.225) rather than the L=.272 that suits an accent's 900.

### Why 500 and 600 are not free

Both are fills that carry white text — `bg-brand` resolves to 600 in light mode
and to 500 in dark — so their lightness is bounded by WCAG AA against white. The
spine's 500 stop sits at .545 rather than a rounder .565 for exactly that
reason: at .565, a 500-stop fill came in at 4.30:1.

`bun run check:contrast` is the gate. It checks all 162 token pairings in both
modes, and it is the thing to run after any palette edit.

## The families

| Family | Hue | Peak chroma | Role |
| --- | ---: | ---: | --- |
| `sand` | 74 | 0.009 | Neutral — every surface, border and text |
| `blue` | 258 | 0.110 | Brand, focus ring |
| `green` | 148 | 0.098 | Success |
| `amber` | 71 | 0.118 | Warning |
| `red` | 30 | 0.142 | Danger |

One warm temperature runs through everything, the grey included — that is the
theme's premise, and the reason it is named for a woven canvas. `sand` sits on
the same hue axis as `amber` (74 against 71), so warning reads as the neutral
turned up rather than a foreign yellow, and its chroma is a whisper (C=.009) —
enough that a surface feels chosen, not enough to force a cast over everything a
consumer builds on top. Chroma everywhere else is deliberately moderate: this
theme has to survive being someone else's brand-adjacent neutral ground. Every
family is wired to a semantic token; the palette carries no spare hues.

## Changing it

**Regenerate the whole spine rather than nudging one value.** An off-spine stop
is precisely the defect this construction removes, and a single hand-tuned hex
stays invisible until it turns up beside its neighbours in a component.

Change one of three things — a family's hue, a family's peak chroma, or a spine
constant — then re-emit all five scales in OKLCH, gamut-map each into sRGB by
reducing chroma until every channel is in range, and write the resulting hex
values into the `:root` block of `src/theme/linen/palette.css`. Then:

```sh
bun run check:contrast          # 162 pairings, both modes — the hard gate
bun run test:stories            # story a11y suite, light and dark
bun run test:visual:update      # baselines change by design when fills move
```

Bump `--theme-version` in the same commit. It is declared as a variable rather
than a comment so anything that wants it can read it at runtime — the
[Theme](?path=/docs/design-system-theme--docs) sheet does exactly that.
